# Бездна — веб-ранобэ о мире океана и ёкаев

**Бездна** — это одностраничное веб-приложение для чтения и редактирования оригинального ранобэ. Сайт полностью работает в браузере, все данные (главы, лор, персонажи) сохраняются в локальном хранилище вашего устройства. Вы можете экспортировать и импортировать резервные копии в формате JSON, переключать светлую/тёмную тему, искать главы, менять размер шрифта и даже редактировать содержимое прямо на сайте через режим разработчика.

## Возможности

- **Главная страница** с обложкой и описанием проекта.
- **Читалка** с удобной навигацией по главам, поиском, настройкой шрифта.
- **Индикатор глубины** — активный уровень Бездны подсвечивается в зависимости от текущей главы (значение глубины настраивается в режиме редактора).
- **Энциклопедия** — редактируемый блок лора (сохраняется автоматически).
- **Карточки персонажей** с иконками и описаниями.
- **Режим разработчика** (Ctrl+E) — позволяет:
  - Редактировать название главы, текст и глубину.
  - Автоматически форматировать вставленный текст в абзацы.
  - Сохранять изменения локально.
- **Экспорт/импорт** всех данных (главы, лор, персонажи) в JSON для резервного копирования или переноса на другой компьютер.
- **Адаптивный дизайн** — удобно на телефонах и компьютерах.
- **Анимированный фон** (волны, реагирующие на прокрутку) и плавные анимации кнопок.

## Как использовать

### Локальный запуск

1. Скачайте файл `index.html`.
2. Откройте его в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Все данные будут храниться в `localStorage` вашего браузера.

### Публикация в интернете

1. Зарегистрируйтесь на [GitHub](https://github.com).
2. Создайте репозиторий с именем `ваш-логин.github.io`.
3. Загрузите `index.html` в этот репозиторий.
4. Включите GitHub Pages в настройках репозитория (ветка `main`).
5. Сайт станет доступен по адресу `https://ваш-логин.github.io`.

## Режим разработчика (редактирование контента)

- Нажмите кнопку **«Правка»** в верхней панели или нажмите **Ctrl+E** (Cmd+E на Mac).
- Появится панель с полями для заголовка, текста главы и выбора глубины.
- Вставьте текст — система автоматически разобьёт его на абзацы (по двойным переносам или по предложениям).
- Нажмите **«Сохранить главу»** — изменения сразу отобразятся в читалке и сохранятся в браузере.
- Вы также можете редактировать **Энциклопедию** прямо на странице (блок с лором — кликните по тексту и пишите), изменения сохранятся автоматически.

### Экспорт и импорт

- В режиме разработчика нажмите **«Экспорт JSON»** — скачается файл со всеми главами, лором и персонажами.
- Чтобы восстановить данные или перенести их на другой компьютер, нажмите **«Импорт JSON»** и выберите ранее сохранённый файл.

## Горячие клавиши

- `Ctrl+E` (Cmd+E) — открыть/закрыть панель разработчика.
- `←` (стрелка влево) — предыдущая глава.
- `→` (стрелка вправо) — следующая глава.
- На телефонах: свайп влево/вправо по экрану для смены главы.

## Настройка темы

- Кнопка **«Тема»** в верхней панели переключает между светлой, тёмной и системной темой (выбор сохраняется).
